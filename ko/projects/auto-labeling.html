Prompt 기반 image·video auto‑labeling

Daedong AILab, Senior AI Researcher, 2024년 5월–현재.

결과: 이미지당 labeling 비용이 Prolific 대비 USD 1.05에서 USD 0.036으로 96.6% 줄었습니다.

역할: 기존 video segmentation 모델 위에 prompting, serving, post‑processing 계층을 만들었습니다.

문제

이 pipeline 전에는 segmentation data와 region‑grounded vision‑language data를 사람이 직접 label했습니다.

맡은 일

Labeling 도구 밖에서는 label taxonomy를 정하고 annotation guideline을 썼습니다. COCO 형식의 training dataset도 만들었습니다. Labeling 뒤에 이어지는 세 단계 captioning pipeline 역시 제 작업입니다.

방법

  1. Click과 mask 수정은 frame이 바뀌어도 같은 ID를 유지하는 tracked mask가 됩니다.
  2. Labeling이 끝나면 open‑weight vision‑language model이 label된 data에 caption을 답니다.

모델 구조

Pipeline은 기존 prompt 기반 video segmentation 모델을 씁니다. Image encoder와 neck이 frame마다 feature를 만들고, mask decoder가 point prompt나 mask prompt를 mask logit으로 바꿉니다. Video에서는 memory 경로가 추적 중인 mask를 저장해 이후 frame으로 넘깁니다.

모델은 공개된 기존 open‑source TensorRT export 위에서 돌아갑니다. 그 export가 모델을 여러 graph로 나누고 memory attention을 sparse하게 바꿨습니다. 이 변경은 export 작성자의 작업입니다. 제 변경은 model weight를 바꾸지 않습니다.

Image labeling

정지 image에는 이전 frame이 없으므로 memory encoder와 object pointer를 쓰지 않습니다. Point‑prompt decoder에서 mask, object score, IoU 출력만 남긴 subgraph를 뽑았습니다. Operator와 weight는 video graph와 같습니다. Encoder와 neck은 image마다 한 번 돕니다. 첫 click은 first‑click decoder로 갑니다. 그다음 click부터는 앞선 click 전부, 그리고 mask prompt 역할을 하는 직전 mask logit과 함께 refine decoder로 들어갑니다.

Video labeling

첫 frame에 이미 있는 label은 model input 크기로 바꾸고 mask logit으로 만들어 conditioning frame으로 넣습니다. Ground 같은 region class는 먼저 object mask의 합집합만큼 잘라 내므로, 겹친 label에서 tracking이 시작되는 일은 없습니다. Click은 그 위에 point prompt로 얹으며, 새 object는 반드시 positive click으로 시작합니다. Annotator가 한 frame을 아직 click하는 동안에는 중간 mask를 memory에 쓰지 않습니다. 최종 mask만 encoding해 저장합니다. 뒤쪽 frame에서 고친 내용도 같은 방식으로, 같은 track ID를 가진 새 conditioning frame으로 더합니다.

출력

Mask logit은 낮은 해상도로 채운 뒤 upsampling해 binary mask로 바꿉니다. Cleanup 단계는 object와 region class가 겹치지 않게 하고, region class의 작은 조각은 이웃 영역에 넘깁니다. 같은 object class끼리 겹친 중복도 지웁니다. 어떤 positive click과도 이어지지 않은 조각은 버립니다. Object는 COCO polygon으로, region class는 mask로 저장합니다.

Serving

Image 경로와 video 경로는 GPU 위의 encoder와 neck 하나를 함께 씁니다. Image feature는 click 사이에 GPU에 남겨 두고, 직전 mask도 마찬가지입니다. FP16 build가 mask IoU check를 통과하지 못해서 point‑prompt decoder는 FP32로 build했습니다. GPU inference와 CPU post‑processing은 별도 service 두 개로 나눠 돌립니다.

Labeling 이후 captioning

Caption은 세 단계로 나뉩니다.

  • Mask마다 그 mask가 덮는 object의 caption을 달았습니다.
  • Mask마다 image와의 관계를 설명하는 caption도 달았습니다.
  • Image 전체에도 따로 caption을 달았습니다.

Caption은 검토를 거치며, 확신이 낮은 경우는 두 번째 검토로 넘깁니다. 검증된 caption은 instance annotation에 연결합니다.

Open‑vocabulary 모델의 caption 학습 업그레이드는 object caption과 image caption으로 학습합니다. Relationship caption은 label과 함께 저장해 두고, 이 학습에는 쓰지 않습니다.
