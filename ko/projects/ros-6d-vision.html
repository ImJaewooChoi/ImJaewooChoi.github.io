Eye‑to‑hand calibration 자동화

PLAIF, Computer Vision Engineer, 2023년 1월–2024년 4월.

결과: ROS trigger로 calibration을 돌리고, capture마다 residual error를 보고합니다. 별도 검증 단계는 robot base frame 기준 marker pose를 출력합니다.

역할: Eye‑to‑hand calibration 자동화와 검증 단계를 만들었습니다.

문제

로봇 밖에 고정한 camera(eye‑to‑hand)는 pose를 camera frame 기준으로 측정합니다. 로봇은 robot base frame 기준 pose가 필요하므로, camera와 로봇 사이 transform을 calibration하고 검증해야 합니다.

방법

  1. ROS trigger가 들어올 때마다 ArUco board를 Zivid로 찍고, robot tool pose를 읽고, point cloud를 함께 써서 marker pose를 추정합니다.
  2. 새 pose 쌍이 들어올 때마다 해를 다시 구합니다. Batch AX = YB solver와 OpenCV Park method가 camera‑to‑robot transform을 추정하고, capture마다 residual error의 평균과 표준편차를 publish합니다.
  3. Capture와 pose 쌍을 저장하므로, 중단된 session을 이어서 진행할 수 있습니다. 종료 요청이 오면 최종 calibration matrix를 저장합니다.
  4. 별도 validation node가 저장된 matrix를 불러와, marker마다 robot base frame 기준 위치와 자세를 보고합니다.
