CAD‑free assembly

PLAIF, Computer Vision Engineer, 2023년 1월–2024년 4월.

문제

CAD model이 없는 부품을 로봇이 조립해야 하고, 실행 중에 쓸 수 있는 것은 2D camera뿐입니다. 그래서 그 image에서 목표 6D tool pose를 구해야 합니다.

맡은 일

Image matching에서 목표 6D tool pose까지 이어지는 pose pipeline을 만들었습니다.

방법

  1. Pipeline은 실시간 2D image를 미리 저장한 reference RGB‑D capture와 LightGlue로 matching합니다. 그래서 match마다 depth가 붙습니다.
  2. 3D‑2D match에서 solvePnP와 RANSAC으로 camera pose를 복원합니다. 여기에 eye‑to‑hand calibration과 저장된 reference pose를 이어 붙여 목표 6D tool pose를 얻습니다.

시스템 구성도

Reference RGB‑D capture는 한 번만 찍습니다. 실행 중에는 2D camera image를 crop하고 grayscale로 바꾼 뒤 matching합니다.

결과

Pipeline은 총 다섯 차례 진행을 마쳤습니다. 사내 시험 1,000회 중 93%가 성공했습니다. 이 작업은 한국 특허 10‑2694987의 기반이며, 저는 이 특허의 공동 발명자입니다.
