CAD‑free assembly

PLAIF, Computer Vision Engineer, 2023년 1월–2024년 4월.

결과: 사내 시험 1,000회에서 task success 93%를 기록했습니다.

역할: 2D camera image에서 목표 6D tool pose를 구하는 pose pipeline을 만들었습니다.

문제

CAD model이 없는 부품을 로봇이 조립해야 합니다. 실행 중에는 2D camera만 쓸 수 있으므로, 그 image에서 목표 6D tool pose를 구해야 합니다.

맡은 일

Image matching부터 목표 6D tool pose까지 pose pipeline을 만들었습니다. 이 작업은 한국 특허 10‑2694987의 기반이며, 저는 이 특허의 공동 발명자입니다.

방법

  1. Segmentation으로 실시간 2D image에서 대상 ROI를 잡고, 이 ROI를 grayscale로 바꿉니다. LightGlue가 ROI의 keypoint를 미리 저장한 reference RGB‑D capture의 image keypoint와 matching합니다.
  2. Essential‑matrix RANSAC을 쓰는 epipolar filter가 two‑view geometry에 맞지 않는 match를 지웁니다. 남은 match는 reference capture에서 depth를 가져오고, 유효한 depth가 없는 match는 버립니다.
  3. solvePnP와 RANSAC이 3D‑2D match에서 현재 camera frame 기준 부품 frame O의 metric pose를 구합니다. 이 pose를 eye‑to‑hand calibration, 저장된 reference tool pose와 이어 목표 6D tool pose를 얻습니다.

Frame은 B가 robot base, E가 tool, R이 reference capture의 camera frame, C가 현재 camera frame입니다. Eye‑to‑hand calibration으로 BTR, BTC를 구합니다. 부품에는 CAD model이 없으므로, 부품에 고정한 frame O를 capture 시점의 R과 같게 둡니다.

TEO=(TRB)−1⁢TErefB
XiO=di⁢KR−1⁢[ui,vi,1]⊤

di는 keypoint (ui, vi)의 reference depth이며 단위는 미터입니다. (ui, vi)는 전체 image 기준 pixel 좌표이고, KR은 reference camera의 intrinsic matrix입니다.

TOC=solvePnPRANSAC({(XiO,xi)})
TEtargetB=TCB⁢TOC⁢TEO

첫 줄은 reference capture와 함께 한 번만 저장합니다. xi는 현재 image에서 match된 keypoint입니다. 셋째 줄은 현재 camera의 intrinsic matrix KC를 써서, 현재 camera frame 기준 부품 frame O의 pose인 CTO를 구합니다.

시스템 구성도

Reference RGB‑D capture는 한 번만 찍습니다. 실행 중에는 segmentation으로 2D camera image에서 대상 ROI를 잡고, grayscale로 바꾼 뒤 matching합니다.
