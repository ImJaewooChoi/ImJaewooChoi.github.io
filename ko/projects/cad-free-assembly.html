CAD‑free Auto Assembly

부품 CAD 없이 2D camera로 조립용 6D tool pose를 구합니다. 사내 1,000회 시험의 task success는 93%입니다. 한국 특허 10‑2694987의 기반입니다.

문제

부품 CAD model이 없을 때 조립용 target 6D tool pose가 필요합니다. 실행 시점의 센서는 3D camera가 아니라 2D camera입니다.

방법

먼저 two‑view RGB baseline을 만들었습니다. Reference 이미지와 target 이미지 사이에서 learned feature matching, USAC essential‑matrix estimation, relative pose recovery, triangulation을 썼습니다.

최종 pipeline은 LightGlue로 live 2D image와 저장된 reference RGB‑D capture를 맞춥니다. Match마다 depth가 붙고, depth가 없는 match는 제거합니다. 3D‑2D match에 solvePnP와 RANSAC으로 camera pose를 구한 뒤, hand‑eye calibration과 저장된 reference pose를 이어 target 6D tool pose를 얻습니다. 사내 시험 1,000회에서 task success 93%를 기록했습니다. 이 작업이 한국 특허 10‑2694987의 기반입니다.

기술

LightGlue, USAC, solvePnP, RANSAC, hand‑eye calibration.
