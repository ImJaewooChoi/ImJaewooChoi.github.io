Open‑vocabulary segmentation과 mapping

Daedong AILab, Senior AI Researcher, 2024년 5월–현재.

문제

자율 과수원 플랫폼 RT100은 고정된 label 목록에 없는 물체도 instance mask로 잡아야 합니다. 그 mask는 Jetson Orin Nano 위에서 주행 가능한 map이 되어야 합니다.

맡은 일

Semantic segmentation과 instance segmentation을 위한 Class‑name open‑vocabulary segmenter(1세대)는 frozen DINOv3와 SigLIP2 encoder 위에서 pre‑training했습니다. 이어서 mask head를 단 Caption‑trained open‑vocabulary detector(2세대)를 만들었습니다. RT100에는 두 세대를 모두 배포했고, 그 instance mask로 occupancy‑grid mapping을 구축했습니다.

방법

Class‑name open‑vocabulary segmenter(1세대)

DINOv3와 SigLIP2 encoder는 고정하고, image adapter, PAN‑FPN neck, text adapter, instance head와 semantic head를 여러 dataset으로 pre‑training했습니다. 두 head는 batch를 번갈아 가며 함께 학습했습니다. Box와 instance mask를 내는 instance head에는 region‑text alignment loss를 걸었고, semantic head는 pixel마다 class‑name text embedding과 비교해 class를 고릅니다. Text‑prompt inference와 fixed‑vocabulary 변환을 넣었고, 모델을 과수원 domain에 맞췄습니다.

2세대가 필요했던 이유

1세대는 class name만 보고 학습했고, SigLIP2 text encoder도 고정돼 있었습니다. Validation subset에서는 가로등 같은 가는 구조물과 책 같은 작은 물체를 놓쳤고, 비슷한 class끼리 헷갈렸습니다. Semantic head는 정해진 목록에서 가장 가까운 class를 고를 뿐, 모르는 물체를 거부하지 못합니다. 그래서 RT100 이미지에서 흰 반사판 일부가 snow로 분류됐습니다. Class name보다 풍부한 text로 학습하려고 Caption‑trained open‑vocabulary detector(2세대)를 만들었습니다. 2세대의 compact text encoder는 object caption과 image caption으로 학습합니다. Caption은 학습 때만 쓰므로 inference 비용은 그대로입니다. Occupancy grid에는 instance mask가 필요합니다. 그래서 detector에 mask head를 달아 box와 함께 mask를 내게 했습니다.

Caption‑trained open‑vocabulary detector(2세대)

2세대는 query‑based transformer 구조입니다. Frozen DINOv3 backbone 뒤에 multi‑scale projector와 three‑layer decoder가 붙습니다. 학습 가능한 compact text encoder가 category name을 embedding합니다. Inference 때는 어떤 category name 목록이든 받고, 그 embedding으로 decoder query를 고르고 class마다 점수를 매깁니다. Mask head는 가장 해상도가 높은 feature를 decoder query와 함께 읽고, mask를 원본 이미지 해상도로 돌려줍니다. 학습에는 category name, object caption, image caption을 씁니다. 학습 중에만, 미리 계산해 둔 language teacher가 caption을 matched query, pooled image feature와 정렬하고 관련 있는 negative의 가중치를 다시 매깁니다. Mask는 matching을 거쳐 BCE/Dice loss로 학습합니다.

Mask를 occupancy grid로

두 세대 모두 같은 mapping 단계를 씁니다. Point cloud를 voxel로 줄이고, 각 voxel 중심을 camera image에 투영합니다. Instance mask 안에 떨어진 voxel은 그 mask의 object와 class를 받습니다. 유효한 anchor depth에서 virtual voxel을 더했습니다. Label이 붙은 voxel은 주행 가능한 occupancy grid에 기록됩니다. 더 이상 관측되지 않는 cell은 decay로 서서히 지워지고, hysteresis는 cell이 free와 occupied 사이에서 뒤집히지 않게 잡아 줍니다. Cost inflation 덕분에 계획 경로는 장애물 가장자리에서 떨어져 지나갑니다. Navigation은 이 grid를 읽습니다.

결과

두 세대 모두 Jetson Orin Nano의 production RT100 perception pipeline에서 TensorRT로 최적화되어 돌아가며, 제 auto‑labeling system이 만든 label로 학습했습니다. 둘 다 box와 instance mask를 내고, 1세대는 semantic mask도 냅니다. 2세대는 ONNX와 TensorRT로 export되며 PyTorch, ONNX Runtime과 parity check를 거칩니다. 작은 물체, 그리고 주어진 category name 어디에도 맞지 않는 물체를 거부하는 일은 2세대 이후에도 남은 과제입니다.
