CAD‑based bin picking

PLAIF, Computer Vision Engineer, 2023년 1월–2024년 4월.

결과: 사내 고정 환경 시험 1,000회에서 object type 다섯 종류를 빈 용기로 옮겨 task success 89%를 기록했습니다.

역할: Instance segmentation model을 학습했고, CAD template 정렬 단계를 만들었습니다.

문제

로봇이 CAD geometry를 아는 물체를 bin에서 꺼내야 합니다. 그러려면 bin을 찍은 RGB‑D image에서 물체마다 pick pose를 구해야 합니다.

방법

  1. Instance segmentation model은 가려지지 않은 물체 class와 hole class를 나눠 학습했습니다. Object mask에서 hole mask를 빼고, 남은 instance mask로 point cloud를 나눴습니다.
  2. Pick pose마다 hidden‑point removal로 visible‑surface CAD template을 만들었습니다. PCA 초기화와 point‑to‑point ICP로 이 template을 segment된 point에 정렬했습니다.
  3. Registration fitness가 낮거나 inlier RMSE가 높은 pose는 버렸습니다. 남은 pose는 순위를 매긴 뒤 camera extrinsics로 robot base frame에 옮겼습니다.

시스템 구성도

요청마다 color, point, normal이 담긴 RGB‑D frame 하나에서 시작합니다. Mask 안의 point는 downsampling하고 normal 방향으로 거른 뒤 PCA에 넣습니다. Reverse check가 각 fit을 양방향으로 평가합니다. 남긴 pose는 ROS action result로 돌아가고, robot motion은 로봇 쪽에서 처리합니다.
