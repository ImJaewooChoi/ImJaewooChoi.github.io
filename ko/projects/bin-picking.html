CAD‑based bin picking

PLAIF, Computer Vision Engineer, 2023년 1월–2024년 4월.

결과: 사내 고정 환경 시험 1,000회에서 object type 다섯 종류를 빈 용기로 옮겨 task success 89%를 기록했습니다.

역할: Instance segmentation model을 학습했고, CAD template 정렬 단계를 만들었습니다.

문제

로봇이 CAD geometry를 아는 물체를 bin에서 꺼내야 합니다. 그러려면 bin을 찍은 RGB‑D image에서 물체마다 pick pose를 구해야 합니다.

방법

  1. Instance segmentation model은 가려지지 않은 물체 class와 hole class를 따로 둡니다. Object mask에서 hole mask를 빼고, 남은 instance mask로 point cloud를 나눕니다.
  2. CAD model 위에 정의한 pick pose마다 hidden‑point removal로 visible‑surface template을 만들고, 그 pick pose의 tool frame 기준으로 바꿔 둡니다. PCA 초기화와 point‑to‑point ICP로 이 template을 segment된 point에 정렬합니다.
  3. Registration fitness가 낮거나 inlier RMSE가 높은 pose는 버립니다. Object마다 점수가 가장 높은 pick pose 하나를 남기고, 남은 pose를 object 사이에서 순위를 매긴 뒤 eye‑to‑hand calibration으로 robot base frame에 옮깁니다.

Frame은 B가 robot base, C가 camera, O가 CAD model, E가 pick pose의 tool frame입니다. E는 CAD model 위에 OTE로 정의합니다. Eye‑to‑hand calibration으로 BTC를 구합니다. Ps와 Pt는 각각 segment된 scene point와 template의 principal‑axis frame입니다.

piE=(TEO)−1⁢piO
TE(0)C=TPsC⁢(TPtE)−1
TEC=argminR∈SO(3),t∈ℝ3∑i‖R⁢piE+t−qj(i)C‖2
TEB=TCB⁢TEC=TCB⁢TOC⁢TEO

첫 줄은 pick pose마다 offline으로 template을 한 번 만듭니다. 둘째 줄은 PCA 초기화이고, 셋째 줄은 여기서 시작하는 nearest‑neighbour point‑to‑point ICP입니다. Cqj(i)는 template point i에 가장 가까운 segment된 point입니다. Segment된 object마다 pick pose별로 ICP를 돌리고, fitness와 RMSE 검사를 통과한 fit 중 점수가 가장 높은 것 하나를 남깁니다. 넷째 줄은 남긴 pose를 robot base frame으로 옮깁니다. Camera frame 기준 object pose는 여기서 따라 나오며 따로 추정하지 않습니다.

시스템 구성도

요청마다 color, point, normal이 담긴 RGB‑D frame 하나에서 시작합니다. Mask 안의 point는 downsampling하고 normal 방향으로 거른 뒤 PCA에 넣습니다. Reverse check가 각 fit을 양방향으로 평가합니다. 남긴 pose는 ROS action result로 돌아가고, robot motion은 로봇 쪽에서 처리합니다.
