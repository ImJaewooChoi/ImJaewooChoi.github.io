Auto‑labeling pipeline

Daedong AILab, Senior AI Researcher, May 2024–Present.

Problem

Segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

Besides building the video auto‑labeling pipeline, I set the label taxonomy and the annotation guidelines and compiled the COCO‑format training datasets.

Method

  1. Point prompts and mask corrections were turned into tracked masks with consistent IDs across frames.
  2. Qwen‑series vision‑language models wrote the region‑grounded object captions and checked them. I sent uncertain cases to a second review and linked the verified captions to the instance annotations.

Model: a tracker built on SAM 3

The labeling tracker is based on the SAM 3 video tracker, compiled to TensorRT engines and driven by clicks and seed masks. Class names and track IDs come from the labeling backend, so the model only has to produce masks. The engines follow an open‑source TensorRT build of that tracker.

How the pipeline uses it

On top of SAM 3, I built the prompting, serving and post‑processing layer.

  1. Clicks on a video frame accumulate. Each new click refines the previous mask on the GPU, and the object's memory is committed only after the last click, so a half‑finished mask never reaches the memory bank.
  2. Image and video requests share one image encoder and neck. Every engine is loaded once per process and shared by concurrent workers.
  3. GPU inference and CPU post‑processing run as separate services. The GPU side returns raw mask logits; the CPU side fills holes, resizes the masks and writes COCO polygons or RLE masks.

Captioning after labeling

After auto‑labeling finished, Qwen‑series vision‑language models captioned the labeled data in three stages:

  • Each mask got a caption of the object it covers.
  • Each mask also got a caption of its relationship to the image.
  • The whole image got a caption of its own.

Result

Labeling one image cost about USD 1.05 before this pipeline and about USD 0.036 after it, a 96.6% reduction.
