Auto‑labeling pipeline

Daedong AILab, Senior AI Researcher, May 2024–Present.

Problem

Segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

I built the video auto‑labeling pipeline, set the label taxonomy and the annotation guidelines, and compiled the COCO‑format training datasets.

Method

  1. I turned point prompts and mask corrections into tracked masks with consistent IDs across frames.
  2. I shared TensorRT engines between image and video inputs, so the same computation is not run twice.
  3. I used Qwen‑series vision‑language models to write region‑grounded object descriptions and to check them. I sent uncertain cases to a second review and linked the verified descriptions to the instance annotations.

Result

Labeling one image cost about USD 1.05 before this pipeline and about USD 0.036 after it, a 96.6% reduction.

Stack

TensorRT, Qwen‑series vision‑language models, and COCO.
