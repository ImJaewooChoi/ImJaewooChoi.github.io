Prompt‑guided image and video auto‑labeling

Daedong AILab, Perception Engineer (official title: Senior AI Researcher), May 2024–Present.

Problem

Before this pipeline, segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

I built image and video annotation on an existing prompt‑guided video segmentation model: an image‑only decoder graph, a click‑refinement flow, selective memory writes, and one shared encoder for both paths. Beyond the annotation tool, I also set the label taxonomy, wrote the annotation guidelines, and built the COCO‑format training datasets.

Method

  1. Clicks and mask corrections become tracked masks that keep the same ID across frames.
  2. Qwen‑series vision‑language models wrote the region‑grounded object captions and checked them. I sent uncertain cases to a second review and linked the verified captions to the instance annotations.

Model structure

The pipeline builds on an existing prompt‑guided video segmentation model. A ViT image encoder turns each image or video frame into tokens, and a neck turns those tokens into a feature pyramid. A prompt encoder and mask decoder turn point or mask prompts into mask logits. Video adds a memory path. There, a memory encoder compresses each tracked mask into memory features and an object pointer, and four memory‑attention layers let the current frame attend to recent frames and up to four conditioning frames.

The model runs on an existing open‑source TensorRT export. That export split the model into separate graphs and made memory attention sparse. Those changes are its author's work. My changes are built on top of it and do not change the model weights.

Image labeling

A still image has no past frames, so the memory encoder and object pointer are not used. I extracted a subgraph of the point‑prompt decoder that keeps only the mask, object score and IoU outputs. Its operators and weights are the same as in the video graph. The encoder and neck run once per image. The first click goes to a first‑click decoder. Each later click goes to a refine decoder together with all earlier clicks and the previous mask logits, which act as a mask prompt.

Video labeling

Existing labels on the first frame are resized to the model input, turned into mask logits and entered as conditioning frames. Region classes such as ground are first trimmed by the union of object masks, so tracking never starts from overlapping labels. Clicks go on top as point prompts, and a new object must start with a positive click. While an annotator is still clicking on a frame, intermediate masks are not written to memory; only the final mask is encoded and stored. A correction on a later frame is added the same way, as a new conditioning frame with the same track ID.

Outputs

Mask logits are filled at low resolution, upsampled and thresholded. Cleanup keeps objects and region classes from overlapping and gives small stray islands of a region class to their neighbours. It also removes overlapping duplicates of one object class. Pieces disconnected from every positive click are dropped. Objects are saved as COCO polygons and region classes as masks.

Serving

The image and video paths share one encoder and neck on the GPU. Image features stay cached on the GPU between clicks, and so does the previous mask. The point‑prompt decoder is built in FP32 because the FP16 build failed the mask IoU check. GPU inference and CPU post‑processing run as two separate services. None of these choices change the model.

Captioning after labeling

After auto‑labeling finished, Qwen‑series vision‑language models captioned the labeled data in three stages:

  • Each mask got a caption of the object it covers.
  • Each mask also got a caption of its relationship to the image.
  • The whole image got a caption of its own.

The second generation of the open‑vocabulary model trains on the object and image captions. It does not use the relationship captions, which are stored with the labels.

Result

Labeling one image cost USD 1.05 with crowdsourced labeling on Prolific and USD 0.036 with this pipeline, a 96.6% reduction. The pipeline is deployed at Daedong AILab, where it has produced 13.0M instance‑mask labels for 1.1M training records (662K images). These labels trained both generations of the open‑vocabulary model.
