Prompt‑guided image and video auto‑labeling

Daedong AILab, Senior AI Researcher, May 2024–Present.

Result: Labeling cost fell from USD 1.05 to USD 0.036 per image (96.6%) compared with Prolific.

Role: Built the prompting, serving, and post‑processing around an existing video segmentation model.

Problem

Before this pipeline, segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

Beyond the labeling tool, I set the label taxonomy, wrote the annotation guidelines, and built the COCO‑format training datasets. The three‑stage captioning that follows labeling is also my pipeline.

Method

  1. Clicks and mask corrections become tracked masks that keep the same ID across frames.
  2. After labeling, open‑weight vision‑language models caption the labeled data.

Model structure

The pipeline uses an existing prompt‑guided video segmentation model. An image encoder and neck turn each frame into features, and a mask decoder turns point or mask prompts into mask logits. For video, a memory path stores each tracked mask and carries it to later frames.

The model runs on an existing open‑source TensorRT export. That export split the model into separate graphs and made memory attention sparse. Those changes are its author's work. My changes do not change the model weights.

Image labeling

A still image has no past frames, so the memory encoder and object pointer are not used. I extracted a subgraph of the point‑prompt decoder that keeps only the mask, object score and IoU outputs. Its operators and weights are the same as in the video graph. The encoder and neck run once per image. The first click goes to a first‑click decoder. Each later click goes to a refine decoder together with all earlier clicks and the previous mask logits, which act as a mask prompt.

Video labeling

Existing labels on the first frame are resized to the model input, turned into mask logits and entered as conditioning frames. Region classes such as ground are first trimmed by the union of object masks, so tracking never starts from overlapping labels. Clicks go on top as point prompts, and a new object must start with a positive click. While an annotator is still clicking on a frame, intermediate masks are not written to memory; only the final mask is encoded and stored. A correction on a later frame is added the same way, as a new conditioning frame with the same track ID.

Outputs

Mask logits are filled at low resolution, then upsampled and turned into binary masks. Cleanup keeps objects and region classes from overlapping and gives small stray islands of a region class to their neighbors. It also removes overlapping duplicates of one object class. Pieces disconnected from every positive click are dropped. Objects are saved as COCO polygons and region classes as masks.

Serving

The image and video paths share one encoder and neck on the GPU. Image features stay cached on the GPU between clicks, and so does the previous mask. GPU inference and CPU post‑processing run as two separate services.

Captioning after labeling

The captions come in three stages:

  • Each mask got a caption of the object it covers.
  • Each mask also got a caption of its relationship to the image.
  • The whole image got a caption of its own.

Captions are checked, and unsure cases get a second review. Verified captions are linked to the instance annotations.

The caption‑trained upgrade of the open‑vocabulary model trains on the object and image captions. It does not use the relationship captions, which are stored with the labels.

Result

The pipeline is deployed at Daedong AILab. Its labels trained the open‑vocabulary perception model and its upgrade.
