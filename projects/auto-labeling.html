Auto‑labeling pipeline

Daedong AILab, Senior AI Researcher, May 2024–Present.

Problem

Segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

Besides building the video auto‑labeling pipeline, I set the label taxonomy and the annotation guidelines and compiled the COCO‑format training datasets.

Method

  1. Point prompts and mask corrections were turned into tracked masks with consistent IDs across frames.
  2. Image and video inputs share TensorRT engines, so the same computation is not run twice.
  3. Qwen‑series vision‑language models wrote the region‑grounded object descriptions and checked them. I sent uncertain cases to a second review and linked the verified descriptions to the instance annotations.

Model: SAM3 tracker via DART

DART (Detect Anything in Real Time), by Mehmet Kerem Turkcan (github.com/mkturkcan/dart, paper arXiv:2603.11441), runs SAM3 with TensorRT. This pipeline uses its TensorRT build of the SAM3 video tracker, prompted with clicks and masks. DART's multi‑class text detector is not used here.

Model structure

The image encoder, a ViT, runs once per frame. A neck turns its output into multi‑scale features. A point‑prompt decoder predicts a mask from the first positive or negative click and refines it with each later click. A mask‑prompt step starts an object from a seed mask instead and encodes it into memory. On later video frames, a memory‑attention step conditions the frame's features on a memory bank of earlier mask memories and object pointers. It predicts the object's mask under the same track ID and writes the result back to the bank. The point decoder and the tracker step both return mask logits with an IoU estimate and an object score.

How the pipeline adapts it

  1. On video, clicks on a frame accumulate, and each new click refines the previous mask on the GPU. The object's memory is committed after the last click, so intermediate clicks never enter the memory bank.
  2. Image requests use point heads cut from the video point‑prompt graphs, which keep the mask, IoU, and object‑score outputs and drop the memory outputs.
  3. Image and video requests share one image encoder and neck. Each engine is loaded once and shared by concurrent workers, and each worker keeps its own execution context.
  4. Selection of memory and query tokens is reimplemented to pick the same tokens as the original without building full‑size mask temporaries.
  5. Each preview session keeps a snapshot of its image features, so later clicks on the same image do not rerun the image encoder.
  6. GPU inference runs in one service and returns mask logits; a separate CPU service fills holes, resizes the masks, and writes COCO polygons or run‑length masks.
  7. A correction at a later frame enters as new clicks or a seed mask at that frame, and the object keeps its track ID.

Result

Labeling one image cost about USD 1.05 before this pipeline and about USD 0.036 after it, a 96.6% reduction.

Stack

TensorRT, Qwen‑series vision‑language models, and COCO.
