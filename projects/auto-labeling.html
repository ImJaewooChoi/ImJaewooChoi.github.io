Prompt‑guided image and video auto‑labeling

Daedong AILab, Senior AI Researcher, May 2024–Present.

Problem

Segmentation data and region‑grounded vision‑language data were labeled by hand.

My role

I adapted an existing segmentation model to the image and video annotation workflow, set the label taxonomy and annotation guidelines, and compiled the COCO‑format training datasets.

Method

  1. Point prompts and mask corrections were turned into tracked masks with consistent IDs across frames.
  2. Qwen‑series vision‑language models wrote the region‑grounded object captions and checked them. I sent uncertain cases to a second review and linked the verified captions to the instance annotations.

Model structure

The pipeline builds on an existing prompt‑conditioned segmentation model. A visual backbone and feature‑projection stage provide shared image features, while point- and mask‑conditioned decoding initializes or refines object masks. Temporal object memory carries information between frames for video tracking.

The model runtime uses an existing open‑source TensorRT implementation.

Adapting the model to annotation

My work focused on adapting this architecture to the annotation workflow:

  1. I derived an image‑only execution graph that excludes video‑specific output branches without changing retained weights or operations.
  2. I reused visual features on the GPU and retained intermediate mask predictions on‑device during iterative correction. Only the final correction is committed to persistent tracking memory.
  3. GPU inference and CPU post‑processing run as separate services, supporting interactive previews and video label propagation within the same workflow.

Captioning after labeling

After auto‑labeling finished, Qwen‑series vision‑language models captioned the labeled data in three stages:

  • Each mask got a caption of the object it covers.
  • Each mask also got a caption of its relationship to the image.
  • The whole image got a caption of its own.

Result

Labeling one image cost about USD 1.05 before this pipeline and about USD 0.036 after it, a 96.6% reduction.
