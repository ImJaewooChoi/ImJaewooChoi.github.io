Strawberry cultivation tasks

Daedong AILab, Senior AI Researcher, May 2024–Present.

Result: Transplanting 93.8%, flower thinning 87.5%, and runner handling 65% task success over 1,000 work cycles per task in a fixed lab environment. Exhibited at CES 2025.

Role: Led the data pipeline and Diffusion Policy training for all three tasks.

Problem

A strawberry cultivation robot has to transplant seedlings, thin flowers, and handle runners. Each task policy is learned from human demonstrations collected with a Universal Manipulation Interface (UMI).

My role

I led the data pipeline and Diffusion Policy training, and every stage in the flow below except the robot‑side post‑processing is my work.

Method

Model structure

The policy is Diffusion Policy. An image encoder turns the RGB frames into features, which form the global conditioning together with the robot state. Starting from a noisy action sequence, the denoising network removes noise over repeated steps and returns an action sequence for the robot side.

Result

The three task policies run on the cultivation robot.
