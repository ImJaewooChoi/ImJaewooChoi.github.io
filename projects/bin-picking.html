CAD‑based bin picking

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Problem

The robot has to pick objects with known CAD geometry out of a bin, so it needs a pick pose for each object from an RGB‑D image of the bin.

My role

I trained the instance segmentation model and built the step that aligns visible‑surface CAD templates to the segmented points.

Method

  1. The instance segmentation model was trained with separate unoccluded and hole classes. Hole masks were subtracted from object masks, and the remaining instance masks segmented the point cloud.
  2. For each pick pose, I built a visible‑surface CAD template by hidden‑point removal and aligned it to the segmented points with PCA initialization and point‑to‑point ICP.
  3. Poses with low registration fitness or high inlier RMSE were dropped. The rest were ranked and transformed into the robot base frame with the camera extrinsics.

System diagram

Each request starts from one RGB‑D frame with color, points, and normals. An instance segmentation model segments the image into unoccluded objects and holes, and hole masks are removed from the object masks. For each instance, the masked points are downsampled and filtered by normal direction, and PCA gives the initial pose. Visible‑surface templates are built offline from the CAD mesh, one per pick pose. Point‑to‑point ICP aligns each template to the points, and a reverse check scores the fit in both directions. The kept pick poses are ranked, mapped from the camera frame to the robot base with the eye‑to‑hand calibration, and returned as a ROS action result. Robot motion is handled on the robot side.

Result

The system is deployed for bin picking. In 1,000 in‑house, fixed‑environment trials, the robot moved five object types into an empty container with 89% task success.
