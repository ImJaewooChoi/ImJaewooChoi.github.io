CAD‑based bin picking

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Result: 89% task success across 1,000 in‑house, fixed‑environment trials, moving five object types into an empty container.

Role: Trained the instance segmentation model and built the CAD‑template alignment.

Problem

A robot has to pick objects with known CAD geometry out of a bin, so it needs a pick pose for each object from an RGB‑D image of the bin.

Method

  1. The instance segmentation model has separate unoccluded and hole classes. Hole masks are subtracted from object masks, and the remaining instance masks segment the point cloud.
  2. For each pick pose defined on the CAD model, a visible‑surface template is built by hidden‑point removal and expressed in that pick pose's tool frame. PCA initialization and point‑to‑point ICP align it to the segmented points.
  3. Poses with low registration fitness or high inlier RMSE are dropped. For each object, the best‑scoring pick pose is kept, and the kept poses are ranked across objects and transformed into the robot base frame with the eye‑to‑hand calibration.

Frames: B is the robot base, C the camera, O the CAD model, and E the tool frame at a pick pose, defined on the CAD model as OTE. Eye‑to‑hand calibration gives BTC. Ps and Pt are the principal‑axis frames of the segmented scene points and of the template.

The first line builds the template once per pick pose, offline. The second line is the PCA initialization, and the third is nearest‑neighbour point‑to‑point ICP started from it, where Cqj(i) is the segmented point nearest to template point i. For each segmented object, ICP runs once per pick pose, and the best‑scoring fit that passes the fitness and RMSE checks is kept. The fourth line maps the kept pose into the robot base frame. The object pose in the camera frame follows from it and is not estimated separately.

System diagram

Each request starts from one RGB‑D frame with color, points, and normals. Before PCA, the masked points are downsampled and filtered by normal direction. A reverse check scores each fit in both directions. Kept poses go back as a ROS action result, and the robot side handles motion.
