CAD‑free assembly

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Result: 93% task success across 1,000 in‑house trials.

Role: Built the pose pipeline that turns a 2D camera image into the target 6D tool pose.

Problem

The robot has to assemble a part that has no CAD model. At run time it has only a 2D camera, so it needs the target 6D tool pose from that image.

My role

I built the pose pipeline, from image matching to the target 6D tool pose. This work is the basis of Korean Patent 10‑2694987, on which I am a co‑inventor.

Method

  1. Segmentation finds the target ROI in the live 2D image, and the ROI is converted to grayscale. LightGlue matches keypoints in the ROI to keypoints in the image of the stored reference RGB‑D capture.
  2. An epipolar filter with essential‑matrix RANSAC removes matches that break the two‑view geometry. Each remaining match takes its depth from the reference capture, and matches without valid depth are dropped.
  3. solvePnP with RANSAC turns the 3D‑2D matches into the metric pose of the part frame O in the live camera frame. Chaining that pose with the eye‑to‑hand calibration and the stored reference tool pose gives the target 6D tool pose.

Frames: B is the robot base, E the tool, R the camera frame of the reference capture, and C the live camera frame. Eye‑to‑hand calibration gives BTR and BTC. The part has no CAD model, so its frame O is fixed to the part and matches R at capture time.

TEO=(TRB)−1⁢TErefB
XiO=di⁢KR−1⁢[ui,vi,1]⊤

Here di is the reference depth in metres at keypoint (ui, vi), given in full‑image pixel coordinates, and KR is the reference camera intrinsic matrix.

TOC=solvePnPRANSAC({(XiO,xi)})
TEtargetB=TCB⁢TOC⁢TEO

The first line is stored once with the reference capture, and xi is the matched keypoint in the live image. The third line gives CTO, the pose of the part frame O in the live camera frame, using the live camera intrinsic matrix KC.

System diagram

The reference RGB‑D capture is taken once. At run time, segmentation finds the target ROI in the 2D camera image, and the ROI is converted to grayscale before matching.
