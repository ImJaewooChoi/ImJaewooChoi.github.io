CAD‑free assembly

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Problem

Assembly needs a target 6D tool pose when the part has no CAD model. At run time the sensor is a 2D camera.

My role

I prototyped a two‑view baseline and built the final pose pipeline.

Method

  1. A two‑view RGB baseline came first. It matched a reference image to a target image with learned features, estimated the essential matrix with USAC, recovered the relative pose, and ran triangulation.
  2. The final pipeline matches the live 2D image to a stored reference RGB‑D capture with LightGlue, so each match carries depth. Matches with no depth are removed.
  3. From the 3D‑2D matches, solvePnP with RANSAC recovers the camera pose, which I chain with the hand‑eye calibration and the stored reference pose to get the target 6D tool pose.

Result

93% of 1,000 in‑house trials succeeded. This work is the basis of Korean Patent 10‑2694987.

Stack

LightGlue, USAC, solvePnP, RANSAC, and hand‑eye calibration.
