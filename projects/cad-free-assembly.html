CAD‑free assembly

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Problem

Assembly needs a target 6D tool pose when the part has no CAD model. At run time the sensor is a 2D camera.

My role

I prototyped a two‑view baseline and built the final pose pipeline.

Method

  1. I prototyped a two‑view RGB baseline: learned feature matching between a reference image and a target image, USAC essential‑matrix estimation, relative pose recovery, and triangulation.
  2. In the final pipeline, LightGlue matches the live 2D image to a stored reference RGB‑D capture, so each match carries depth. Matches with no depth are removed.
  3. solvePnP and RANSAC estimate the camera pose from the 3D‑2D matches. That pose is chained with the hand‑eye calibration and the stored reference pose. The result is the target 6D tool pose.

Result

Task success was 93% across 1,000 in‑house trials. This work is the basis of Korean Patent 10‑2694987.

Stack

LightGlue, USAC, solvePnP, RANSAC, and hand‑eye calibration.
