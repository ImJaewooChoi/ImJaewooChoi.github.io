ROS 6D vision server

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Problem

A caller needs the object pose in the robot base frame and in the camera frame. The camera also has to be calibrated to the robot.

My role

I wrote the ROS action server and the eye‑to‑hand calibration tools.

Method

  1. The server runs capture, segmentation, and pose estimation per request, and returns robot‑base and camera‑frame poses with matching scores.
  2. A configuration file selects the camera (Zivid, RealSense, or recorded data), the model, and the pipeline.
  3. Eye‑to‑hand calibration uses ArUco board pose estimation, the OpenCV Park method, and a batch AX = YB solver that reports residual error. A validation tool checks the calibration. Runtime parameters use ROS dynamic_reconfigure.

Result

Each request returns the object pose in the robot base frame and in the camera frame, with a matching score.

Stack

ROS, Zivid, RealSense, ArUco, OpenCV, and dynamic_reconfigure.
