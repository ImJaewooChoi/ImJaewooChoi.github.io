Eye‑to‑hand calibration automation

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Result: Calibration runs from ROS triggers, and the residual error is reported after every capture. A separate validation step outputs marker poses in the robot base frame. The calibration tools are deployed and in use.

Role: Built the eye‑to‑hand calibration automation and its validation step.

Problem

A camera fixed outside the robot (eye‑to‑hand) measures poses in its own frame. The robot needs them in its base frame, so the camera‑to‑robot transform has to be calibrated and then checked.

Method

  1. Each ROS trigger captures a Zivid frame of an ArUco board, reads the robot tool pose, and estimates the marker poses with help from the point cloud.
  2. Every new pose pair updates the solution. A batch AX = YB solver and the OpenCV Park method estimate the camera‑to‑robot transform, and the mean and standard deviation of the residual error are published after each capture.
  3. Captures and pose pairs are saved, so an interrupted session can resume. A stop request writes the final calibration matrix.
  4. A separate validation node loads the saved matrix and reports each marker's position and orientation in the robot base frame.
