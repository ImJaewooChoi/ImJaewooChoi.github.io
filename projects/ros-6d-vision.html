ROS 6D vision server

PLAIF, Computer Vision Engineer, Jan. 2023–Apr. 2024.

Problem

Each request returns an object pose in the robot base frame and in the camera frame, so the camera has to be calibrated to the robot.

My role

I wrote the ROS action server and the eye‑to‑hand calibration tools.

Method

  1. On each request, the server runs capture, segmentation, and pose estimation.
  2. A configuration file selects the camera (Zivid, RealSense, or recorded data), the model, and the pipeline.
  3. The eye‑to‑hand transform is computed from ArUco board poses with the OpenCV Park method and a batch AX = YB solver that reports residual error. I also added a validation tool and ROS dynamic_reconfigure for runtime parameters.

Result

Each request returns the pose in the camera frame and in the robot base, with a matching score.

Stack

ROS, Zivid, RealSense, ArUco, OpenCV, and dynamic_reconfigure.
